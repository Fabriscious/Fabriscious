## 📊 Featured Projects

### 🏥 Medical Platform Analytics

**Healthcare Analytics · Synthetic Data · 300K Appointments · 50K Patients · 2023–2025**

End-to-end analytics project simulating a regional healthcare platform, from synthetic data generation and MySQL modelling to SQL analysis, DAX and Power BI reporting.

**Focus:** appointment behaviour, no-shows, reminders, revenue, patient segmentation and business performance.

**Selected findings**

* **€25.4M** paid revenue over three years
* **7.0%** overall no-show rate
* **5.96%** no-show rate with reminders vs **10.12%** without reminders

[View Repository](https://github.com/Fabriscious/Medical-Platform-Report) · [Watch Project Walkthrough](https://youtu.be/TkfvKTz7-CI)

### ⚡ Energy Transition in Italy

**Energy Analytics · Public Data · Terna + Eurostat · 2010–2024**

Analytics project based on real public data, combining Python data preparation, MySQL star-schema modelling, SQL analysis and Power BI.

**Focus:** electricity generation mix, renewable energy, regional production, European comparison, electricity balance and demand forecast accuracy.

**Selected findings**

* Renewable share of electricity production increased from **23.44% in 2010 to 43.85% in 2024**
* Analysis covers Italian regional production and comparison with selected European countries
* Terna demand-forecast accuracy is evaluated using **MAPE**

[View Repository](https://github.com/Fabriscious/energy-transition-italy) · [Watch Project Walkthrough](https://youtu.be/WxP-wGQiOds)
